Common Questions
Is InfluxDB free to use?
Yes. InfluxDB 3 Core is open source and free to download and run with no license required. InfluxDB 3 Enterprise includes a 30-day free trial—no credit card needed. InfluxDB Cloud Serverless also has a free tier with limited data ingestion rates and 30-day retention. Paid plans unlock higher rate limits, unlimited data retention, and enterprise features.
What's the difference between InfluxDB 3 Core and InfluxDB 3 Enterprise?
Core helps teams build telemetry systems. Enterprise ensures those systems can run the business. InfluxDB 3 Core is an open source, single-node engine, ideal for edge deployments, local development, and lightweight applications. InfluxDB 3 Enterprise is a self-managed production deployment that offers high availability, multi-node clustering, read replicas, long-range data compaction, SAML/SSO, and a technical support SLA. Both products run on your own infrastructure: on-prem, private cloud, or 
How does InfluxDB Cloud Serverless pricing work?
Cloud Serverless uses usage-based pricing across four dimensions: data in ($0.0025/MB), query count ($0.012 per 100 executions), storage ($0.002/GB-hour), and data out ($0.09/GB). There's no minimum commitment or long-term contract on the usage-based plan. New paid accounts receive $250 in credits applied to the first 30 days. Annual plans are also available for organizations that want discounted rates in exchange for a usage commitment— contact sales
for details.
What's the difference between Cloud Serverless and Cloud Dedicated?
Cloud Serverless is a multi-tenant, shared-infrastructure service with elastic, usage-based billing designed for smaller or variable workloads. Cloud Dedicated is a single-tenant private cluster managed by InfluxData, built for production-scale workloads that require performance isolation, unlimited scale, high availability, private networking (available as an add-on), SAML/SSO (add-on), and a technical support SLA.
What is Amazon Timestream for InfluxDB?
Amazon Timestream for InfluxDB is a fully managed InfluxDB service deployed natively on AWS. It's billed directly to your AWS account, so existing AWS credits and Enterprise Discount Program (EDP) discounts apply. It integrates natively with IAM, VPC, and Secrets Manager, and supports multi-AZ high availability. It's the right fit for AWS-native organizations that want to consolidate InfluxDB billing into their cloud spend without managing infrastructure.
Can I subscribe to InfluxDB through AWS, GCP, or Azure Marketplace?

What's the difference between self-managed and fully managed InfluxDB?
Self-managed options, InfluxDB 3 Core and InfluxDB 3 Enterprise, run on your own infrastructure (on-prem, private cloud, or edge), giving you full control over data residency, deployment architecture, and security configuration. Fully managed options—Cloud Serverless, Cloud Dedicated, and Amazon Timestream for InfluxDB—are operated by InfluxData or AWS, so there's no infrastructure to provision, patch, or scale yourself.
What security certifications does InfluxDB have?
InfluxData is certified for SOC 2 Type II, ISO 27001, and ISO 27018 across its product line. All products support GDPR-configurable data handling. Cloud Dedicated and InfluxDB 3 Enterprise support SAML/SSO (as an add-on and natively, respectively). Cloud Dedicated also offers private networking as an add-on. For self-managed deployments, InfluxData's certifications provide the framework; you configure your own requirements on top.

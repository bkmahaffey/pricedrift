What is an Uptime Monitor?
Uptime Monitors are simple monitors that measure availability and performance of URLs, TCP connections, and Heartbeats from passive processes like Cron Jobs.
What is an API check?
API checks are monitors that do POST, GET, and other typical HTTP requests. You have full control over the payload, headers, etc. You can also create assertions to check if the response from your API is valid and performant. For billing, we count any HTTP request as a check run. They can be scheduled to run every 10 seconds, while a 1-second interval is available upon request for API checks.
What is a browser check?
Browser checks are monitors based on Node.js scripts using frameworks like Playwright. Each browser check uses an actual Chrome browser to execute navigation, fill out forms and validate if these interactions have the correct results. This is also commonly called “synthetic monitoring”. For billing we count every executed script as a check run. Browser check runs have a timeout threshold of 120 seconds.
Are Traces and Status Pages included in any plan?
These are available as add-ons and can be purchased separately. You can learn more from their respective product pages.
How can I add features like private locations or visual regression testing?
These are available in Team and Enterprise plans.
What is the difference between Round Robin and Parallel scheduling?
Round Robin scheduling runs checks sequentially across locations. Parallel allows them to run simultaneously for faster feedback, available only on Enterprise.

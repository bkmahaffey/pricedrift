What is an Uptime Monitor?
Uptime Monitors are simple monitors that measure the availability and performance of URLs, TCP connections, ICMP pings, DNS records, and Heartbeats from passive processes like Cron Jobs.
What is an API Check?
API Checks are monitors that do POST, GET, and other typical HTTP requests. You have full control over the payload, headers, etc. You can also create assertions to check if the response from your API is valid and performant. They can be scheduled to run as often as every 10 seconds, while a 1-second interval is available upon request.
What is a Browser Check?
Browser Checks are monitors based on Node.js scripts using the open-source Playwright testing framework. Each Browser Check uses an actual browser to execute navigation, fill out forms and validate if these interactions have the correct results. This is also commonly called “synthetic monitoring”. For billing, we count every executed script as a check run. Browser check runs have a timeout threshold of 2 minutes.
What is a Playwright Check Suite
Playwright Check Suites are similar to Browser Checks, but are able to run your Playwright Test suites completely natively, with custom dependencies, share storage state, and more.
Playwright Check Suites are equal to a single Browser Check running for 30 seconds. For each 30 seconds they run, it will consume one more check run, i.e. a 45 second Playwright Check Suite will consume 2 runs.
What is a Status Page
Status pages provide transparent communication about your service health and incidents to customers, users, and stakeholders. Checkly’s status pages automatically reflect your monitoring results and create a professional interface for incident communication.

What is the difference between Round Robin and Parallel scheduling?
Round Robin scheduling runs checks sequentially across locations. Parallel allows them to run simultaneously for faster feedback.

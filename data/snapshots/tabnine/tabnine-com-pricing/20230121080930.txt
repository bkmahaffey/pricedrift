Features / Plans
Basic model
Short code completions for simple projects.
Tabnine’s basic AI model is trained on open
source code with permissive licensing.
Advanced AI models
Whole-line completions, Full-function completions
and natural language to code completions are
powered by a set of advanced, large-scale
transformer-based machine learning models that
produce longer and more accurate code completions.
Trained on open source code with permissive licenses.
Code-native models
Our advanced pre-trained AI models are specifically
designed to accommodate language-specific coding
subtleties, and increase suggestion relevance based on
your tech stack. Supports JavaScript, TypeScript,
Python, Java, PHP, Ruby, Go, and C++.
Private repo model Optional
Integrate your selected repositories on GitHub,
Gitlab, or Bitbucket, to provide your private repo
model with higher context of your coding
patterns and style to improve your code
suggestions.
Priority support
Got a question? Need some help?
Tabnine’s engineers are ready to assist you.
Self hosting
For organizations requiring an additional layer of
security, Tabnine Enterprise offers a self-hosting
solution.
All of your Tabnine Enterprise private AI models
will be trained and hosted on your organization's
local servers or private cloud, giving you
complete privacy and full control over all your
data.

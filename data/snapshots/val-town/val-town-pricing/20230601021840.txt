- Vals are JavaScript & TypeScript code run on our servers
- Vals can be scheduled (like a cron job)
or accessed via API
- Email yourself:
console.email("message", "Subject Line")
- Store state:
@me.fizz += "buzz"
- Reference your vals:
@me.fizz.split('buzz').length
- Reference others' vals:
@stevekrouse.moreBuzz()
- Reference personal secrets:
@me.secrets.openai
- Import npm:
const _ = await import("npm:lodash-es")
- Import Deno:
const { DOMParser } = await import("https://deno.land/x/deno_dom@v0.1.38/deno-dom-wasm.ts")
- Run keyboard shortcut:
cmd +enter

Bear with us as we upgrade your account manually. Hopefully it takes just a couple of minutes, but it might take a couple of hours if we’re sleeping. A “run” is any evaluation of code on Val Town. It can be triggered in the app, on a schedule, or via API. These limitations only apply to runs on your account, and do not include when others use your vals as libraries. It does count when others hit your API.
Total storage represents your storage usage across the whole platform, including all versions of vals and their associated tracing.

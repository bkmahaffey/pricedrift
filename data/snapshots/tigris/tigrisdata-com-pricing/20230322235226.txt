Frequently Asked Questions
What is a Database Request Unit (DRU)?
Database reads and writes are mapped to database request units. A unit is a read or write up to 4KB in size. A request that performs 4KB write maps to a single RU. A request that performs 8KB read maps to 2 RUs.
How is the Storage size calculated?
The storage size is the max storage consumed in any given month. This is the logical dataset size.
What is a Search Request Unit (SRU)?
A search request unit is a metric that measures the number of searches performed.
What is the Index size metric?
The index size is the total size of the indexed documents in the search index. This is the logical size.
How does the Index size metric relate to the number of documents?
The number of documents that can fit a certain index size can be calculated based on the average size of indexed fields in a document. Given that the free plan has 250MB of index size, it can translate to the number of documents as follows:
1KB average size of indexed fields per document = 250K documents
0.5KB average size of indexed fields per document = 500K documents
10KB average size of indexed fields per document = 25K documents

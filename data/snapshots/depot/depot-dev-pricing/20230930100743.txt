Common Questions
What is the free tier?
Each plan includes a free tier of 60 build minutes and 50GB cache storage per month. Any usage above the free tier build minutes is billed monthly.
What are build minutes?
Build minutes track the time builds run on a given builder. Each build minute is exactly equivalent to a real time minute.
Are there discounts for non-profits or open-source?
Yes! Please contact us
with more information about your project and for more details.
Can I self-host Depot?
Projects can use Depot-hosted builders, or you can connect your own cloud account
to run builds on self-hosted builders on the Committed Usage plan.

Common Questions
What is a project?
You can think of a project as a cache namespace for your builds. You can use a single namespace for a single git repository or Dockerfile, or use one namespace for multiple git repositories or Dockerfiles.
Projects can use Depot-hosted builders, or you can connect your own cloud account
to run builds on self-hosted builders on the Enterprise plan.
What are build minutes?
Build minutes track the time builds run on a given builder. Each build minute is exactly equivalent to a real time minute.
What is the free tier?
The free tier includes 60 build minutes, 1 project, and 1 user. For the team and business plans, any usage above the free tier build minutes is billed monthly.
Are there discounts for non-profits or open-source?
Yes! Please contact us
with more information about your project and for more details.
